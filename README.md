# Gantt_AKI

Proyecto para gestionar cronogramas y planificación de actividades con enfoque en AKI.

## Descripción

Este repositorio está pensado para documentar, organizar y compartir información relacionada con la planificación de tareas, seguimiento de hitos y visualización de cronogramas tipo Gantt.

## Objetivo

- Centralizar información de actividades y fechas.
- Facilitar la coordinación de trabajo.
- Presentar avances de forma clara y visual.

## Estructura sugerida

```text
Gantt_AKI/
├── README.md
├── docs/
│   └── planificacion.md
├── data/
│   └── tareas.csv
├── scripts/
│   └── generar_gantt.py
└── assets/
    └── gantt.png
```

## Uso

1. Revisar la planificación en `docs/planificacion.md`.
2. Actualizar la información de tareas en `data/tareas.csv`.
3. Ejecutar scripts de apoyo para generar gráficos o reportes.
